# Inteligencia Analitica - Grupo

App web analitico das tres casas: Dois Rios (Campos do Jordao), a bela Sintra (Sao Paulo) e Chiado (Moema).

Modulos: visao geral, faturamento diario, estrutura de custos, simulador de cenarios operacionais, mao de obra, tributario, parecer e consolidado do grupo.

Os dados lancados ficam no navegador de cada usuario. Este repositorio hospeda apenas o codigo do app.
